# Questões de POO II

Resolução de questões práticas em Java sobre classes genéricas (generics) e composição.

**Disciplina:** Programação Orientada a Objetos II  
**Tecnologias:** Java

## Questões

| Pasta | Conteúdo |
|---|---|
| `PrimeiraQuestao/` | `Caixa<T>`: classe genérica que guarda qualquer tipo, usada com `Produto` |
| `SegundaQuestao/` | `Produto<T>` com identificador genérico, valor e datas de fabricação e vencimento |
| `TerceiraQuesta/` | `Pedido` com produtos, incluindo o subtipo `Eletronico` |
| `QuartaQuestao/` | `DicionarioGenerico` e `Par` usando generics |

## Como executar

Cada exercício é um projeto do IntelliJ IDEA. Abra a pasta do exercício no IntelliJ e rode a classe `Main`, ou pelo terminal:

```bash
cd "<pasta-do-exercicio>/src"
javac *.java
java Main
```
